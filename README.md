# 项目风险分析助手

## 项目描述

这是一个基于Flask和AI的项目风险分析助手，用于分析项目风险和Bug情况，为用户提供专业的分析建议。

## 功能特点

- 项目风险分析
- Bug情况分析
- AI聊天界面
- 项目信息查询
- 项目管理助手

## 部署步骤

### 1. 准备服务器

选择一台服务器，确保：
- 安装了Python 3.10+
- 具有公网IP地址
- 开放了5002端口

### 2. 克隆代码

```bash
git clone <代码仓库地址> jira_risk
cd jira_risk
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

### 4. 配置环境

根据需要修改配置文件，如JQL模板等。

### 5. 启动服务

#### 开发环境

```bash
python e.py --api
```

#### 生产环境

使用Gunicorn作为WSGI服务器：

```bash
pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:5002 e:app
```

### 6. 访问应用

打开浏览器，访问 `http://<服务器IP>:5002` 即可使用应用。

## 版本控制

建议使用Git进行版本控制，保持服务器上的版本稳定，本地进行开发和测试。

### 分支管理

- `main` 分支：用于部署到生产环境的稳定版本
- `dev` 分支：用于开发和测试新功能

### 部署流程

1. 在 `dev` 分支上开发和测试
2. 测试通过后，合并到 `main` 分支
3. 在服务器上拉取 `main` 分支的最新代码
4. 重启服务

## 注意事项

- 确保服务器有稳定的网络连接
- 定期备份重要数据
- 监控服务运行状态
- 及时更新依赖包

## 技术栈

- Flask：Web框架
- OpenAI：AI模型
- Gunicorn：生产级WSGI服务器
- HTML/CSS/JavaScript：前端界面
